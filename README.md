# FeeFlow Pro — Fee Management System

A fee management web app for schools, academies and institutes. Manage classes, students, monthly fees, payments, receipts and reports in one place.

**Live demo:** https://shahzaibarshad8688-art.github.io/FeeFlow/

## Features

- Classes and student records
- Monthly fee tracking and payment entry
- Fee receipts
- Fee reports
- Runs in the browser, no install needed

## Tech

HTML, CSS, JavaScript (single page), Chart.js, Firebase

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.
